# Обработка измерений температуры

Небольшой воспроизводимый пример: pandas читает таблицу, локальный модуль
`lab.stats` использует NumPy для среднего и выборочного стандартного отклонения.
Данные синтетические и служат для проверки упаковки, а не для научного вывода.

## Входные данные

`data/measurements.csv`: столбец `sample` — группа измерений,
`temperature_c` — температура в градусах Цельсия. Для каждой группы нужны
минимум два конечных значения.

## Запуск

Из корня распакованного проекта, Python 3.11 или новее:

```sh
python -m venv .venv
.venv/bin/python -m pip install numpy==2.4.6 pandas==3.0.6
.venv/bin/python experiment.py
```

В Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.
Версии прямых зависимостей указаны в `pyproject.toml`; это не lock-файл
с транзитивными зависимостями и не гарантия одинаковых вычислений на всех ОС.

## Результат

Программа печатает CSV и записывает его в `outputs/summary.csv`.
Эталон для приложенных данных — `expected/summary.csv`:

```csv
sample,count,mean_c,sample_std_c
A,3,21.000,1.000
B,3,31.000,1.000
```

Никакие файлы не скачиваются, сеть не используется. Архив содержит исходный
проект для загрузки в упаковщик; готового пакета воспроизводимости в нём нет.
